# 模板一：骨架生成器（交互式）

> **适用场景**：只有一个模糊想法，需要 AI 帮你搭建多套剧情结构方案供选择。
>
> **使用方式**：直接复制下方提示词的全部内容发送给 AI，AI 会通过提问引导你完成参数收集。
>
> **在整体流程中的位置**：① 骨架生成器 → ② 大纲填充器 → ③ 主模板（剧本生成）

---

## 📌 与上下游的数据关系

```
【上游输入】
  无（本模板是起点）

【本模板输出】→ 保存至 {项目根目录}/01-创意方案/
  ├── 方案A-骨架结构.md
  ├── 方案B-骨架结构.md
  └── 方案C-骨架结构.md

【下游使用】
  用户从三套方案中选择一套 → 交给模板二（大纲填充器）继续展开
```

## 📂 本模板输出目录结构

```
{项目根目录}/01-创意方案/
├── 方案A-骨架结构.md      # 第一套剧情结构方案

```

**执行步骤**：

3. 生成方案B，保存为 `01-创意方案/方案B-骨架结构.md`
4. 生成方案C，保存为 `01-创意方案/方案C-骨架结构.md`

### 需要收集的信息（按顺序提问，每次只问一个）

请严格按以下顺序，一个问题一个问题地向我提问，每个问题都要提供清晰的示例：

**问题1：项目根目录是什么？**
- 示例：C:\Users\Administrator\Desktop\短剧项目\
- 示例：D:\影视创作\我的第一部短剧\
- 说明：所有输出文件都会保存在这个目录下

**问题2：剧本的题材是什么？**
- 示例：都市逆袭 - 一个普通人通过努力或机遇实现逆袭
- 示例：甜宠 - 甜蜜的爱情故事，全程撒糖
- 示例：虐恋 - 情感纠葛，充满误会和痛苦
- 示例：悬疑 - 悬疑破案，充满谜团
- 示例：古装 - 古代背景，武侠/宫廷/仙侠
- 示例：复仇 - 主角为了复仇而展开剧情
- 示例：搞笑 - 轻松搞笑，娱乐性强

**问题3：请用大白话描述你的大致想法**
- 示例：一个穷小子其实是豪门继承人，被老婆家人看不起，后来反转打脸
- 示例：穿越到古代，从废柴王爷变成一代帝王
- 示例：职场小白遇上霸道总裁，开启逆袭之路
- 示例：富家千金隐藏身份体验生活，被误认为是打工妹
- 说明：简单描述即可，不需要详细

**问题4：总共计划多少集？**
- 示例：80集
- 示例：100集
- 示例：50集
- 说明：短剧通常在50-100集之间

**问题5：你想要什么感觉？**
- 示例：越看越爽，打脸越多越好 - 全程爽感，不断打脸
- 示例：前期虐后期爽 - 先让观众憋屈，后期集中爆发
- 示例：甜到掉牙 - 全程撒糖，甜蜜温馨
- 示例：紧张刺激 - 悬疑烧脑，全程紧张
- 示例：笑到肚子疼 - 轻松搞笑，全程欢乐

**问题6：主要受众群体是谁？**
- 示例：25-35岁女性 - 偏好情感类、甜宠类
- 示例：18-30岁男性 - 偏好逆袭、爽文类
- 示例：全年龄段 - 需要老少皆宜
- 说明：这会影响剧情风格和内容尺度

**问题7：是否有特别想要加入的元素或情节？**
- 示例：必须有身份反转 - 主角真实身份震惊众人
- 示例：必须有打脸情节 - 反派嚣张后被打脸
- 示例：必须有误会情节 - 主角被误解、被冤枉
- 示例：必须有复仇情节 - 主角为复仇而战
- 示例：没有特别要求

**问题8：希望主角是什么类型？**
- 示例：屌丝逆袭型 - 从底层到顶层
- 示例：高冷型 - 全程高冷，霸气侧漏
- 示例：搞笑型 - 幽默风趣，逗比搞笑
- 示例：深情型 - 对感情专一深情
- 示例：腹黑型 - 外表善良内心腹黑

**问题9：反派势力如何设计？**
- 示例：家族内斗 - 主要是家族内部矛盾
- 示例：商场竞争 - 商业上的利益冲突
- 示例：武林恩怨 - 武林中的恩怨情仇
- 示例：多重反派 - 多个不同势力的反派

**问题10：结局偏好吗？**
- 示例：大团圆结局 - 主角幸福圆满
- 示例：开放式结局 - 留有悬念和想象空间
- 示例：悲情结局 - 为了突出主题而悲剧收尾
- 示例：由你来决定
