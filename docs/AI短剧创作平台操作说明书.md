## 1. 系统登录与身份验证

### 1.1 系统访问
- 打开浏览器，访问系统地址（如：http://localhost:5174）
- 系统会自动跳转到登录页面

### 1.2 登录页面概述
登录页面采用现代化的分屏设计：
- **左侧区域**：品牌展示区，包含平台Logo、系统名称、特色功能介绍和背景视频
- **右侧区域**：登录交互区，提供多种登录方式

### 1.3 短信登录
短信登录是推荐的便捷登录方式：

1. 在登录页面顶部选择"短信登录"标签
2. **输入手机号**：
   - 点击"请输入手机号"输入框
   - 输入11位有效手机号码（格式要求：以1开头，第二位为3-9）
3. **图形验证码**：
   - 查看并输入图形验证码
   - 如看不清可点击刷新按钮重新加载
4. **获取短信验证码**：
   - 点击"获取验证码"按钮
   - 系统将发送6位验证码到您的手机
   - 按钮进入60秒倒计时冷却状态
5. **输入验证码**：在"验证码"输入框中输入收到的短信验证码
6. **完成登录**：点击"立即登录"按钮
7. **成功跳转**：登录成功后自动跳转到短剧创作首页

### 1.4 密码登录
对于已有账号的用户，可使用密码登录：

1. 切换到"密码登录"标签
2. **输入账号**：
   - 在"账号/手机号"输入框中输入您的账号或手机号
3. **输入密码**：
   - 点击输入框右侧的眼睛图标可显示/隐藏密码
   - 输入您的登录密码
4. **图形验证码**：输入图形验证码
5. **记住我（可选）**：
   - 勾选"记住我"复选框，下次访问时可快速登录
6. **忘记密码**：
   - 如忘记密码，点击"忘记密码"链接进入找回密码流程
7. **立即登录**：点击"立即登录"按钮完成登录

### 1.5 用户注册
新用户需要先注册账号：

1. 在登录页面底部，点击"免费注册"链接
2. 页面切换到注册表单
3. **输入手机号**：输入您的手机号码
4. **设置密码**：
   - 密码长度要求6-16位
   - 建议包含字母和数字组合
5. **图形验证码**：输入图形验证码
6. **获取验证码**：点击"获取验证码"并输入短信验证码
7. **输入内侧码**：输入内测码（如适用）
8. **立即注册**：点击"立即注册"按钮完成注册
9. 注册成功后自动登录并跳转到首页

### 1.6 找回密码
如忘记密码，可通过以下步骤重置：

1. 在密码登录页面点击"忘记密码"链接
2. **输入手机号**：输入绑定的手机号
3. **验证身份**：
   - 输入图形验证码
   - 获取并输入短信验证码
4. **设置新密码**：
   - 输入新密码（6-16位）
5. **重置并登录**：点击"重置并登录"按钮
6. 系统使用新密码自动登录

### 1.7 安全提示
- 请勿将验证码告知他人
- 建议定期更换密码
- 如账号异常请及时联系客服

## 2. 首页

### 2.1 首页概述
首页是AI短剧创作的起点，提供两大创作入口和近期作品管理功能。页面采用沉浸式视频背景，分为上部创作区和下部作品展示区。

### 2.2 页面结构
- **顶部标题区域**：包含产品设计说明按钮、主标题和副标题
- **创作卡片区域**：提供AI灵感生成和导入已有剧本两个选项卡
- **近期作品区域**：展示最近创作的短剧作品

### 2.3 AI灵感创作
#### 2.3.1 功能入口
在首页创作卡片中，默认显示"AI灵感生成"选项卡。

#### 2.3.2 输入创作灵感
1. **故事内容输入框**：
   - 在文本框中输入您构思的故事内容
   - 示例：一个在赛博朋克世界里寻找失踪妹妹的私家侦探...
   - 实时显示输入字数
2. **内容操作**：
   - **清空内容**：点击垃圾桶图标可清空输入框
   - **AI润色**：点击"AI润色"按钮，AI将优化您的故事描述
3. **选择文本模型**：
   - 点击AI模型选择器，选择合适的AI文本生成模型
4. **开始创作**：
   - 点击"立即创作"按钮，系统将基于您的灵感开始创作
   - 创作过程中显示加载动画和提示信息

#### 2.3.3 热门题材灵感
页面下方提供多个热门题材灵感标签，点击可快速填充故事灵感：
- 包含多种主流短剧题材（如：甜宠、虐恋、悬疑、穿越等）
- 点击任意题材标签，系统自动打开灵感配置对话框
- 在对话框中可进一步完善作品信息

#### 2.3.4 灵感配置对话框
当您选择热门题材或点击"立即创作"后，会打开"开启灵感之门"配置对话框：

**左侧标签页导航**：
- 基础信息
- 故事背景
- 角色档案
- 故事设定
- 故事梗概

**基础信息配置**：
1. **作品名称**：
   - 输入短剧名称
   - 可点击"AI润色"让AI优化标题
2. **题材类型**：
   - 从下拉菜单选择题材
   - 或选择"自定义"手动输入题材
3. **主角设定**：
   - 选择预设的主角类型
   - 或自定义主角名称
4. **视频风格**：选择视频画面风格（如：写实、卡通、二次元等）
5. **视频比例**：选择视频画幅比例（9:16竖屏、16:9横屏、1:1正方形）
6. **目标受众**：选择主要观看人群
7. **集数设置**：设置总集数（默认80集）
8. **每集时长**：设置每集预期时长（30-300秒）

**故事背景配置**：
1. 切换到"故事背景"标签
2. 详细描述故事的世界观、时代背景和环境设定
3. 可使用AI润色功能优化描述
4. 示例提示：这是一个什么样的世界？发生在什么时代？有什么特殊规则？

**角色档案配置**：
1. 切换到"角色档案"标签
2. 详细描述主要角色，包括：
   - 姓名、年龄、外貌特征
   - 性格特点和行为习惯
   - 成长背景和人生经历
   - 核心动机和目标追求
   - 弱点和内心矛盾
3. 可使用AI润色功能

**故事设定配置**：
1. 切换到"故事设定"标签
2. 描述故事的核心冲突、关键事件和戏剧性元素
3. 可使用AI润色功能

**故事梗概配置**：
1. 切换到"故事梗概"标签
2. 撰写完整的故事大纲
3. 可使用AI润色功能

**完成配置**：
- 配置完成后，点击"开始创作"
- 系统将基于配置生成短剧大纲和剧本

### 2.4 导入已有剧本

#### 2.4.1 切换到导入模式
1. 在创作卡片中点击"导入已有剧本"标签
2. 显示文件上传区域

#### 2.4.2 上传剧本文件
1. **文件拖拽**：
   - 将剧本文件直接拖拽到上传区域
2. **点击选择**：
   - 点击上传区域的"点击上传"文字
   - 在文件选择器中选择剧本文件
3. **支持格式**：
   - DOCX文档
   - PDF文档
   - TXT纯文本
4. **文件要求**：
   - 文件大小适中
   - 内容不超过10万字
5. **上传成功**：
   - 文件上传后自动解析内容
   - 系统进入剧本编辑页面

### 2.5 近期作品管理

#### 2.5.1 作品列表展示
- 在首页下方显示"近期作品"区域
- 以网格卡片形式展示最近的短剧作品
- 每个卡片包含：
  - 作品预览图（前3张缩略图）
  - 作品标题
  - 更新时间
  - 集数标签
  - 标识（如为示例作品）

#### 2.5.2 作品操作
1. **打开作品**：
   - 点击任意作品卡片，进入该剧集的详情页面
2. **管理作品**：
   - 点击右上角"管理作品"按钮
   - 进入作品列表页面，可查看和管理所有作品

#### 2.5.3 空状态
当无近期作品时，显示友好的空状态提示：
- "暂无制作中的短剧"
- "开启您的第一场AI剧本创作之旅吧"

## 3. 灵感创作/小说导入

### 3.1 AI灵感创作详细流程

#### 3.1.1 配置故事参数
1. **作品信息**：
   - 作品名称：输入吸引人的标题
   - 题材类型：选择匹配的题材分类
   - 目标受众：定位您的观众群体

2. **角色配置**：
   - 主角设定：选择或自定义主角
   - 可添加多个配角

3. **风格设置**：
   - 视频风格：写实、动漫、水墨等
   - 画面比例：竖屏、横屏或正方形
   - 集数时长：设定每集长度

#### 3.1.2 完善故事设定
1. **故事背景**：
   - 时代背景：古代、现代、未来等
   - 地理环境：故事发生的地点
   - 世界观设定：特殊的规则和设定

2. **角色档案**：
   - 详细描述主角的外貌、性格、背景
   - 设定主角的目标和动机
   - 描述主要配角信息

3. **故事冲突**：
   - 核心冲突：主角面临的主要挑战
   - 关键事件：推动剧情的重要节点
   - 主题思想：作品想表达的核心内容

#### 3.1.3 生成故事梗概
1. 填写完所有信息后，检查确认
2. 点击"生成故事"按钮
3. AI将自动生成完整的故事大纲
4. 生成完成后进入大纲编辑页面

### 3.2 小说导入详细流程

#### 3.2.1 准备小说文件
1. 确保小说格式为支持的格式（DOCX/PDF/TXT）
2. 建议小说包含完整的章节结构
3. 文件大小不超过限制

#### 3.2.2 上传与解析
1. 按照2.4节步骤上传文件
2. 系统自动解析小说内容
3. 识别章节标题、人物对话、场景描述

#### 3.2.3 内容调整（可选）
1. 查看解析结果
2. 如需要可手动调整章节划分
3. 确认主要人物和故事线

### 3.3 从灵感生成大纲
无论使用哪种方式开始创作，都会进入大纲编辑环节，详见第5章"剧本创作"。

## 4. 剧集管理

### 4.1 剧集列表页面概述
剧集管理页面用于查看和管理短剧的所有分集，提供不同创作阶段的筛选和批量操作功能。

### 4.2 页面结构
- **顶部导航栏**：返回按钮、剧集总数徽章、搜索筛选区、标签切换、产品设计说明
- **主内容区**：剧集卡片网格展示
- **底部分页**：分页导航（当剧集较多时）

### 4.3 查看剧集列表

#### 4.3.1 剧集总数展示
页面左上角显示总剧集数量，采用渐变色设计的徽章，包含：
- 魔法棒图标
- "共X集"文字（X为实际集数）

#### 4.3.2 搜索与筛选
1. **搜索框**：
   - 在搜索输入框中输入关键词
   - 可按剧集集数或标题搜索
   - 实时过滤显示结果
2. **状态筛选**（预留功能）：
   - 可按创作状态筛选：剧本创作、主体设置、分镜视频、已完成

#### 4.3.3 标签页切换
页面顶部提供多个状态标签页，点击可切换查看不同阶段的剧集：
- 全部剧集
- 剧本创作中
- 主体设置中
- 分镜制作中
- 已完成

### 4.4 剧集卡片详解

每个剧集以卡片形式展示，包含以下元素：

1. **封面区域**：
   - 剧集封面图片
   - 悬停时显示"上传封面"和"AI生成"按钮
   - 已完成的剧集显示时长标签
   - 左上角显示集数编号（如：第1集）

2. **信息区域**：
   - 剧集标题
   - 当前状态标签（剧本创作/主体设置/分镜视频/已完成）

3. **操作按钮**：
   - **编辑按钮**：点击进入剧集详情编辑
   - **预览按钮**：（仅已完成状态可用）点击播放预览视频

### 4.5 剧集封面管理

#### 4.5.1 上传自定义封面
1. 鼠标悬停在剧集卡片上
2. 点击"上传封面"按钮
3. 在文件选择器中选择图片文件
4. 支持JPG、PNG等常见图片格式
5. 上传成功后自动更新封面

#### 4.5.2 AI生成封面
1. 鼠标悬停在剧集卡片上
2. 点击"AI生成"按钮
3. 系统基于剧集内容自动生成封面图片
4. 生成完成后自动应用到剧集

### 4.6 编辑剧集信息
1. 点击剧集卡片上的"编辑"按钮
2. 或直接点击剧集卡片进入详情页
3. 在打开的编辑侧边栏中修改剧集信息：
   - 剧集标题
   - 剧集描述
   - 其他元数据
4. 保存修改

### 4.7 预览已完成剧集
1. 找到状态为"已完成"的剧集
2. 点击"预览"按钮
3. 在弹出的对话框中播放完整视频
4. 支持播放控制（暂停、进度条、音量等）

### 4.8 批量导入分镜（分镜视频标签页）
在"分镜视频"标签页中，可批量导入分镜：

1. 切换到"分镜视频"标签
2. 点击顶部"批量导入分镜"按钮
3. 选择导入方式：
   - 文件导入：上传分镜脚本文件
   - 手动创建：逐个添加分镜
4. 按照提示完成导入操作

### 4.9 分页功能
当剧集数量较多时，使用底部分页导航：
- 可选择每页显示数量（12/24/36/48集）
- 支持跳转到指定页码
- 显示总剧集数和当前页码信息

## 5. 剧本创作

### 5.1 大纲视图

#### 5.1.1 进入大纲视图
从首页点击作品或从剧集管理进入某一作品后，首先看到的是大纲视图。

#### 5.1.2 大纲结构展示
- 左侧导航：大纲章节列表
- 主编辑区：选中章节的详细内容
- 右侧工具区：AI辅助功能按钮

#### 5.1.3 编辑故事大纲
1. **章节管理**：
   - 查看所有章节列表
   - 点击章节可查看详情
   - 拖动可调整章节顺序
2. **章节内容编辑**：
   - 在主编辑区修改章节标题
   - 编辑章节概要内容
   - 设置章节的关键情节点
3. **AI辅助创作**：
   - 选中任意章节
   - 点击"AI续写"按钮
   - AI将生成下一章节的内容建议
   - 或点击"AI优化"改进当前章节

### 5.2 剧本编辑

#### 5.2.1 剧本格式说明
系统支持专业的剧本格式，包含：
- 场景标题
- 动作描述
- 角色名称
- 对话内容
- 旁白/内心独白

#### 5.2.2 剧本编辑操作
1. **创建新剧本**：
   - 从大纲切换到剧本视图
   - 系统自动根据大纲生成初始剧本
2. **编辑剧本内容**：
   - 点击任意剧本段落进行编辑
   - 使用编辑器工具栏格式化文本
   - 支持加粗、斜体、下划线等样式
3. **AI辅助修改**：
   - 选中一段剧本
   - 选择"AI润色"使表达更生动
   - 选择"AI扩写"增加细节
   - 选择"AI缩写"精简内容

#### 5.2.3 分场拆分
1. 将剧本按场景进行拆分
2. 每个场景作为独立的创作单元
3. 可单独为每个场景设置：
   - 场景描述
   - 出场人物
   - 所需道具
   - 拍摄建议

### 5.3 剧本导出
1. 完成剧本编辑后，点击"导出"按钮
2. 选择导出格式：
   - Word文档（.docx）
   - PDF文档（.pdf）
   - 纯文本（.txt）
3. 文件自动下载到本地

## 6. 主体设置

### 6.1 主体管理概述
主体设置（资产管理）页面用于管理短剧创作所需的角色形象、场景背景、道具等视觉资源，确保视频风格统一。

### 6.2 角色管理

#### 6.2.1 角色列表
- 显示剧中所有主要角色
- 每个角色卡片包含：
  - 角色头像/形象图
  - 角色名称
  - 角色类型标签（主角/配角/龙套）
  - 生成状态

#### 6.2.2 添加新角色
1. 点击"添加角色"按钮
2. 填写角色基本信息：
   - 角色姓名
   - 角色类型（主角/配角）
   - 角色描述（外貌、性格等）
3. **生成角色形象**：
   - 点击"AI生成形象"
   - 系统基于描述生成多张形象图
   - 选择最满意的一张作为主形象
4. **上传自定义形象**（可选）：
   - 如已有设计图，可直接上传
   - 支持图片格式：JPG、PNG
5. 保存角色信息

#### 6.2.3 编辑角色
1. 点击角色卡片进入编辑
2. 修改角色描述
3. 重新生成或更换角色形象
4. 保存修改

#### 6.2.4 角色一致性设置
为确保角色在不同场景中保持一致：
1. 打开角色详情
2. 启用"角色一致性"开关
3. 设置一致性强度参数
4. 后续视频生成都将使用此角色作为参考

### 6.3 场景管理

#### 6.3.1 场景库
- 按剧情需要分类管理场景
- 常见分类：室内、室外、特殊场景等
- 每个场景包含场景图和描述

#### 6.3.2 添加场景
1. 点击"添加场景"按钮
2. 输入场景名称和描述
3. 选择场景类型
4. **AI生成场景**：
   - 点击"AI生成场景图"
   - 输入场景细节描述
   - 生成并选择满意的场景图
5. 或上传已有场景图片
6. 保存场景

### 6.4 道具与元素管理
管理视频中可能用到的道具、特效元素等：
1. 添加常用道具到资源库
2. 为道具添加描述和标签
3. 支持AI生成或上传自定义道具图

### 6.5 资源使用
在剧本创作或分镜编辑时，可以：
1. 快速引用已设置的角色
2. 选择合适的场景背景
3. 添加需要的道具元素
4. 系统会自动确保视觉一致性

## 7. 分镜视频

### 7.1 分镜管理概述
分镜视频页面将剧本转化为可视化的分镜脚本，并提供AI视频生成功能。

### 7.2 分镜列表

#### 7.2.1 查看分镜
- 以时间轴或卡片形式展示所有分镜
- 每个分镜显示：
  - 分镜序号
  - 分镜缩略图（如已生成）
  - 分镜描述
  - 镜头类型（全景/中景/近景/特写等）
  - 生成状态

#### 7.2.2 分镜筛选
- 按状态筛选：待生成/生成中/已完成
- 按场景筛选
- 按角色筛选

### 7.3 创建分镜

#### 7.3.1 自动生成分镜
1. 在剧本编辑完成后，点击"生成分镜"
2. 系统自动将剧本拆解为分镜：
   - 根据场景切换自动划分
   - 识别镜头类型
   - 生成分镜描述
3. 检查自动生成的分镜
4. 手动调整不满意的部分

#### 7.3.2 手动编辑分镜
1. 点击任意分镜进行编辑
2. 修改分镜描述
3. 选择或调整镜头类型：
   - 全景：展示环境
   - 中景：展示人物动作
   - 近景：展示人物表情
   - 特写：突出细节
4. 设置画面时长
5. 选择角色和场景（从主体设置中选择）
6. 添加运镜方式（固定/推拉/摇移/跟拍等）
7. 添加备注信息

#### 7.3.3 分镜预览图
1. 选中分镜后，可生成预览图
2. 点击"生成预览图"按钮
3. AI根据描述生成单帧画面
4. 预览图用于确认视觉效果

### 7.4 视频生成

#### 7.4.1 单个分镜生成
1. 在分镜列表中选择一个分镜
2. 点击"生成视频"按钮
3. 配置生成参数：
   - 视频模型选择
   - 画面质量设置
   - 运动强度
4. 确认后开始生成
5. 生成过程中显示进度条
6. 完成后可预览视频

#### 7.4.2 批量生成
1. 勾选多个需要生成的分镜
2. 点击"批量生成"按钮
3. 确认生成任务
4. 系统按顺序逐个生成分镜视频
5. 可在任务列表查看进度

#### 7.4.3 视频调整
如生成的视频不满意：
1. 点击分镜的"重新生成"按钮
2. 或点击"编辑提示词"
3. 修改画面描述
4. 再次生成

### 7.5 视频合成

#### 7.5.1 合成整集视频
当所有分镜视频都生成完成后：
1. 进入视频合成页面
2. 检查分镜顺序是否正确
3. 添加转场效果（可选）
4. 配置背景音乐（可选）
5. 点击"合成视频"
6. 系统将所有分镜拼接为完整视频

#### 7.5.2 添加音频
- 支持AI配音：输入文字自动生成语音
- 支持上传音频文件
- 支持背景音乐选择和音量调节

#### 7.5.3 导出最终视频
1. 视频合成完成后预览
2. 如满意点击"导出"
3. 选择视频格式和清晰度
4. 下载到本地或保存到作品库

### A. 常见问题

**Q: AI生成的内容不满意怎么办？**
A: 可以尝试优化提示词，或选择不同的AI模型再次生成。也可以手动编辑修改。

**Q: 生成视频需要多长时间？**
A: 根据视频长度和画质要求不同，通常10-60秒视频需要1-5分钟。

**Q: 可以导出无水印的视频吗？**
A: 高级及以上会员可导出无水印视频。

**Q: 作品数据安全吗？**
A: 系统采用加密存储，数据仅您和授权的团队成员可见。
