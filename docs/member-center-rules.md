# 会员中心 · 算力豆规则说明

> 版本：v2.8 · 敬龙版（积分合并模式）  
> 生效日期：2026-07-24  
> 适用范围：会员中心（MemberCenterView.vue）

---

## 一、基础关联类

### 1. 单一积分池

所有算力豆为**单一积分池**，不存在"月度豆"与"长效豆"的区分。

- 会员套餐赠送的算力豆与充值购买的算力豆**合并到同一个池**
- 积分按 **"1元 = 100积分"** 等面值发放
- 会员档位之间**不存在赠送比例差异**（溢价体现在功能权益，不在积分数量）

### 2. 有效期按会员周期月计算

"当月"按**会员周期月**计算，即**开通日起30天**，不是自然月。

- **示例**：7月20日开通，有效期至 8月19日
- **原因**：月中开通的用户如果用自然月只能使用几天，会产生大量客诉

### 3. 非会员使用规则

不买会员、仅充值算力豆：可正常使用基础生成功能，但受非会员限制。

**可用功能**：480P/720P视频 · 图片 · 文本

**非会员限制**：
- 带水印
- 仅个人用途授权
- 并发 1 个
- 标准队列
- 无 API

> 1080P、去水印商用授权、多并发、优先队列、API 均为会员专属

## 二、会员过期

### 1. 积分随会员到期清零

会员套餐赠送的算力豆，**随会员到期日一起清零**，不结转、不返还。

### 2. 纯充值用户的积分永久保留

单独充值（不购买会员）的算力豆**永久有效**，无会员状态下可继续使用，但按非会员权限执行（带水印、480P/720P、1并发）。

---

## 三、跨档位升级

### 核心逻辑：积分合并 + 有效期延长 + 权益升级

**示例场景**：

> 用户先购买 ¥100 A套餐（100积分），使用15天后还剩15天、200积分。
> 再购买 ¥1000 B套餐（1000积分）。
> 
> **结果**：
> - 积分：200（剩余）+ 1000（新）= **1200积分**
> - 有效期：15（剩余天数）+ 30（新套餐天数）= **45天**
> - 权益：立即切换为 **B套餐全套权益**

### 规则明细

1. **积分合并**：新套餐积分与剩余积分**相加**，用户不吃亏

2. **有效期延长**：新套餐天数加到剩余天数上，不做重置

3. **权益即时升级**：会员权益**立即切换**为新档位全套，即时生效

4. **纯充值不受影响**：此前单独充值（非会员套餐）的算力豆完全不受升级影响，永久保留

## 四、补充底层规则

### 等面值发放 · 无套利空间

- 所有算力豆均按 **"1元 = 100积分"** 等面值发放
- 会员档位之间**不存在赠送比例差异**
- 溢价体现在**功能权益**，不在积分数量
- 上述规则下不存在套利空间，可以放心实现
