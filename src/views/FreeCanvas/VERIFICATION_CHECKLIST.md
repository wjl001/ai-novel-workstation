## 四、架构说明

```
FreeCanvas/
├── components/
│   ├── Scene3DEditPanel.vue    ← 导演台主面板（全屏模态）
│   │   ├── 相机Tab      (位置/注视点/FOV/焦距/景别/运镜)
│   │   ├── 灯光Tab      (CRUD + 参数编辑)
│   │   ├── 材质Tab      (颜色预览 + RGB编辑)
│   │   ├── 环境Tab      (天空/地面/光照/雾/阴影)
│   │   ├── 对象Tab      (CRUD + 位置/规模/材质)
│   │   ├── 道具Tab      ← PropLibraryPanel (150+模型)
│   │   ├── 动作Tab      ← ActionLibraryPanel (100+动作)
│   │   ├── 运镜Tab      ← CameraLibrary (机位/运镜)
│   │   └── 导出Tab      ← ExportPanel (视频录制/导出)
│   ├── TimelineBar.vue         ← 时间轴（播放+关键帧+轨道+缩放）
│   ├── CameraLibrary.vue       ← 运镜库
│   ├── ActionLibraryPanel.vue  ← 动作库面板
│   ├── PropLibraryPanel.vue    ← 道具库面板
│   ├── ExportPanel.vue         ← 动态导出面板
│   └── Scene3DNode.vue         ← 3D视口渲染
├── composables/
│   ├── usePropLibrary.ts       ← 道具库数据（150+）
│   └── useActionLibrary.ts     ← 动作库数据（100+）
├── utils/Scene3DPreview.ts     ← 默认数据工厂
└── types.ts                    ← 完整类型系统
```
