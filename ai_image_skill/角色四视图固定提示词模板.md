## 人物真实感专项优化要求（告别模型脸）

### 核心三原则



1. **真实源于瑕疵**：适当的毛孔、细纹、肤色不均、细小绒毛，是 "人感证据"

2. **高光来自结构**：高光应该小、碎、局部，随鼻梁 / 颧骨 / 下唇等骨骼和湿润区域产生，不是整张脸都亮

3. **情绪落实成动作**：不写心理，写镜头能拍到的连续微动作（视线先转开，头部随后跟随，眼睑微微收缩，嘴角轻微牵动）

### 描述顺序强制要求

**脸 → 肤质 → 光线 → 情绪**（先修骨肉，再注入灵魂）

### 皮肤四维度描述



1. 当前物理状态（干燥 / 出油 / 出汗 / 年龄）

2. 不同区域不同纹理（额头 / 鼻翼 / 面颊 / 眼下 / 嘴唇各不同）

3. 保留适当瑕疵（毛孔 / 细纹 / 肤色不均 / 细小绒毛）

4. 让光线和皮肤发生真实反射（高光集中在鼻梁 / 颧骨 / 下唇）

### 景别匹配细节量



* 全身图：重点描述整体肤色和暴露皮肤

* 近景：加入毛孔、汗毛、眼下纹理、唇纹

* 特写 / 微距：不要什么都写，一次抓一个重点
