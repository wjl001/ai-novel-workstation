## 标准输出格式规范

1. 整体固定分为三大模块，顺序不可调换：**正面提示词 → 负面提示词 → 推荐生成参数**
2. 正面提示词内部固定包含 4 个【】标签项，依次为：【画质前缀】【时空坐标】【场景设计】【分层光影构图】
3. 标签名统一用【】包裹，标签后直接衔接对应内容；分层光影构图下的前景 / 中景 / 背景 / 光线 / 色彩 / 构图 / 三视图输出分点保留换行
4. 无多余前缀语、无加粗标记、无多余分割线，纯文本可直接复制粘贴到提示词编辑框

## 场景真实感专项优化要求

### 核心六原则
1. **空间透视准确**：一点透视/两点透视，空间不扭曲，比例不失调，视线引导明确
2. **材质真实可信**：木质有纹理包浆，金属有氧化反光，石材质感自然，不塑料不虚假
3. **光影有来源**：每个光源都有明确来源（窗户/油灯/霓虹/月光/顶部破损），不凭空发光
4. **前中后景分层**：空间层次分明，每层都有具体物品，不空旷不毛坯
5. **细节有使用痕迹**：磨损/灰尘/年代感/使用痕迹，不崭新不洁净，符合剧情时间线
6. **色调服务于情绪**：冷暖对比，主色调+点缀色，色彩叙事表达剧情情绪

### 光影五维度强制控制
1. 光源类型：点光源/平行光/散射光，来源明确
2. 光质：硬光（阴影锐利戏剧感）/软光（阴影柔和自然）/散射光
3. 方向：正面/侧面/逆光/顶光/底光
4. 明暗：高对比/低对比/过渡细腻，角落自然暗角
5. 色温：暖光/冷光/自然光，冷暖光源对比

### 色调冷暖法则
- 冷色为主，暖色点缀。冷色负责世界（规则/压抑/异化），暖色负责情绪（记忆/人性/希望）
- 暖色越少，出现时越有叙事价值
- 先定情绪色调，再设计场景

### 三视图一致性要求
- 全景建立空间：整体结构、建筑风格、空间尺寸感
- 中景聚焦核心：主要道具、人物互动、光线氛围
- 细节强化氛围：关键道具、机关装置、隐藏线索、材质纹理
- 三视图空间结构一致，光影方向一致，色调一致
